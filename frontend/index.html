What is Python Anatomy?

Python Anatomy is an interactive way to learn how Python code works. Choose any part of a program—from a whole function down to one word or symbol—to see what it means, why it is there, and how it connects to the rest of the code.

Start with the full program, then explore functions, loops, values, and individual pieces of Python syntax.
